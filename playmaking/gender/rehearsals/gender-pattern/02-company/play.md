# One Interview Slot

## Estate

KHAI Gender rehearsal fixture.

## Name

One Interview Slot.

## Arc

Two evaluators review one application for the last interview slot. A preliminary recommendation opens deliberation. The decision remains with the two evaluators.

## Company

- Chair Morgan Hale values rapid triage. Under time pressure Morgan relies on unwritten expectations of who can work without supervision.
- Reviewer Sam Reed values consistent criteria. Sam has the written rubric and can ask the chair to explain any departure from it.
- Place: the lab's hiring room. Both evaluators can see the application and its routing slip. Only they can alter the slip.
- Pieces: an application with the name Emily Ellis and a work sample meeting the written criterion for independent lab work, a rubric, and a routing slip with an optional extra proof requirement.

## Pattern wiring

This Play uses [Gender](../../../pattern.md) in [The Routing Slip](plot.md). The offered [Attributed Standing](../../../position-attributed-standing.md) applies to the offstage applicant as read by Morgan during that Plot.

| Gender requires | This Play supplies |
| --- | --- |
| Reader and setting | Morgan Hale, the hiring chair, reads the application in the lab hiring room described in [Company](#company). Sam witnesses the Chair's treatment. |
| Observable cue and timing | [Plot Cue](plot.md#cue) establishes when Morgan can see the name. [Stage 1](plot.md#stage) specifies Morgan's interpretation of it. |
| Consequence visible in action | [Stage 2](plot.md#stage) puts the additional proof requirement on the routing slip despite the qualifying work sample. Sam can see and challenge the mark. The interview decision remains open. |

## Triggers

Begin after both evaluators have read the qualifying work sample, as Morgan turns the application over to reveal the name.

## Stakes

One slot remains. Imposing an extra proof requirement can consume the time needed to advance the application. Either evaluator can challenge the preliminary routing.
