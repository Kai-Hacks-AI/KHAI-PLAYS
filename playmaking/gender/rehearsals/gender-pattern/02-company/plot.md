# The Routing Slip

## Cue

Both evaluators have read the qualifying work sample. Morgan turns over the application and reads the name Emily Ellis. Sam can see the name and both evaluators can see the routing slip.

## Action

The Chair makes the required preliminary routing mark, then the evaluators can argue for or against it. Only the preliminary mark is fixed. The interview decision stays open.

## Stage

1. Morgan reads the name as feminine.
2. Morgan gives that reading weight in assessing independence and marks the optional extra proof requirement despite the qualifying work sample. Sam can observe the mark and question the discrepancy against the rubric.
3. Both evaluators deliberate and decide whether to offer the interview.

## Tension

Sam can challenge the unequal burden of proof. Morgan can defend, reconsider, or withdraw it. Neither has yet committed the last slot.
