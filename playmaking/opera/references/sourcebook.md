# Write a Sourcebook

Use a Sourcebook to document the evidence and reasoning behind a Playwright’s design or a Director’s staging decision. Keep the Sourcebook with the work or collection it documents. The person responsible for the decision records the rationale and links to the files that carry it.

Use these four chapters in order.

## Line of Work

State what the work is trying to do and which design or staging decision this Sourcebook explains.

## Origin

Identify the internal and external sources that informed the decision. Link to the relevant passage, version, or rehearsal record. Say how each source relates to the work.

## Restrictions

State how far the evidence supports the decision. Distinguish supported claims, open questions, and adaptations that still need rehearsal. Name any boundaries a future author or Director should carry forward.

## Encoding

Link to the file and section where each supported idea becomes a choice someone can use. Describe the connection from source to authored detail, staging direction, or other decision. Keep the working instruction in the object that carries it.

The four chapters follow the [legacy LORE warrant standard](https://github.com/ChBrain/khai/blob/c8c56c7e843eac2eb33709d06ad1d7aca4dd8c00/packages/khai-arch/architecture/reference.md).
