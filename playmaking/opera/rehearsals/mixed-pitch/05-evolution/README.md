## 1. Did the Updated Guides Support the Switch and Return?

**Yes, with the explicit Pitch-transition instructions in the shared Promptbook (`4 / 4` runs clean; `2 / 2` Condition B runs switched cleanly into `Quiet Wonder` for Plot 2 and returned cleanly to `Dry Comedy` for Plot 3).** This does not independently establish that the Director skill alone would produce the same transitions.

- **Standard Tenors ([pitch-defaults.md](../../../skills/khai-playwright/references/pitch-defaults.md)):** Validated directly by an organic observation in [03-mixed-wonder-r2-b.md](../04-runs/03-mixed-wonder-r2-b.md#L125): because the preserved PR #20 card [pitch-dry-comedy.md](../02-company/variant-b/pitch-dry-comedy.md#L13) phrased its `Tenor` around the single-scene beat (`"Play the question with the dry practicality of a parade logistics problem"`), pairing it with `play.md`’s `comic` standard Tenor anchored Plots 1 and 3 where no question is being asked—matching the exact improvement already modeled in [pitch-defaults.md](../../../skills/khai-playwright/references/pitch-defaults.md#L21) (`"Play · Comic. Play the crossing with the deadpan practicality of parade logistics."`).

## 2. Smallest Optional Revision Warranted by the Evidence

No change is needed inside [pitch.md](../../../skills/khai-playwright/references/pitch.md) or [pitch-defaults.md](../../../skills/khai-playwright/references/pitch-defaults.md)—both worked cleanly as written on this branch.

- **One small optional alignment on the Director side ([khai-director/SKILL.md](../../../skills/khai-director/SKILL.md#L9)) for a separate follow-up PR if desired:**
  - *Evidence:* On this fixture, clean transition and zero lingering `Quiet Wonder` in Plot 3 relied on [02-company/promptbook.md](../02-company/promptbook.md#L11-L26) explicitly instructing the Director to check Pitch links at every Plot boundary and replace the previous Plot’s Pitch in isolated performer contexts. Meanwhile, [khai-director/SKILL.md](../../../skills/khai-director/SKILL.md#L9) currently reads *"Use any active Pitch to tune pacing, attention, and staging"* without mentioning Plot-boundary Pitch switches or return to the Play’s default.
  - *Smallest candidate wording (`khai-director/SKILL.md` line 9):*
    > `Use the Play’s default Pitch and any Plot- or object-linked Pitch in scope to tune pacing, attention, and staging, updating the active Pitch when a Plot overrides it or returns to the default.`
