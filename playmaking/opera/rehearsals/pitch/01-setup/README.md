# Rehearsal Setup · The Giant’s Shoe

Two parade volunteers carry a giant papier-mâché shoe across the square. The heel is starting to buckle. A child steps beside them and asks, “Is the giant coming?”

## Create

Use the [Playwright skill](../../../skills/khai-playwright/SKILL.md) to author a short Play and Promptbook, two distinct volunteer Personas, the square as a Place, and the shoe as a Piece. Give both volunteers a reason to care about getting the shoe across the square. Keep the child’s question fixed and leave the volunteers’ response open.

Use [TO TUNE](../../../skills/khai-playwright/references/pitch.md) to author two versions of the same Pitch. Keep Taxonomy, Owner, Undertow, Nerve, and Echo identical. Change only Tenor.

| Variant | Tenor |
| --- | --- |
| Dry comedy | Play the question with the dry practicality of a parade logistics problem. |
| Quiet wonder | Give the question the quiet seriousness the child gives it. |

## Rehearse

Use the [Director skill](../../../skills/khai-director/SKILL.md). Run each Tenor twice in fresh contexts. Give each run only its active Pitch at the same link in the Play. Use the same Company, opening, and child’s line. Let the volunteers choose whether to speak, act, or stay silent. End after one short exchange and its immediate consequence.

## Review

Record the tested commit, Company, runs, observations, and any proposed template edit in SCORE. Cite a line, gesture, or silence per run. Compare how the question lands across Tenors and across repeats of the same Tenor. Record any additional direction the Director supplied and any change to the fixed opening or cue.
