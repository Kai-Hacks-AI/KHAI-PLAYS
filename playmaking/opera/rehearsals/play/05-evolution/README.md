## 2. Proposed Refinements to `khai-playwright/SKILL.md` and `references/play.md`

1. **Include closed-world constraint updates alongside link updates on focused revisions (`khai-playwright/SKILL.md` `## Deliver the work`):**
   - *Evidence:* In Pass 2, Playwright 2 reused `6` existing files untouched (`persona-lena.md`, `persona-bram.md`, `pitch-working-waterway-realism.md`, and three `Pieces`) while updating `11` files—not only to add links to [piece-mill-race-key.md](../02-company/revised/piece-mill-race-key.md) and [process-mill-race-bypass.md](../02-company/revised/process-mill-race-bypass.md), but also because `Place ## Withheld`, `ENACTS ## Triggers`, and `Promptbook ## Knowledge` contained closed-world statements (`"no spare water"`, `"three courses"`) that the new key changed ([revision-note-focused.md](../02-company/revision-note-focused.md#L44)).
   - *Smallest edit (`SKILL.md` line 41):*
     > `Give each new object its own Markdown document. For a focused brief, return the requested objects and update the links and constraints affected by the change.`

2. **State entry-point naming (`play.md` / `promptbook.md` vs. `ENACTS.md` / `PROMPTBOOK.md`) if shelf tooling expects a fixed filename:**
   - *Evidence:* Reading *"The ENACTS document gives the reader an entry point into the work, and the separate Promptbook gives the conditions for performing it"* ([SKILL.md](../../../skills/khai-playwright/SKILL.md#L39)), Playwright 1 named the two files `ENACTS.md` and `PROMPTBOOK.md` ([authoring-note-initial.md](../02-company/authoring-note-initial.md#L24)), whereas earlier single-scene rehearsals used `play.md` and `promptbook.md`. Both staged cleanly; naming a default filename only matters if repository or shelf indexing expects one convention.

3. **Clarify baseline vs. cross-Plot state in `Piece ## Place` for multi-Plot Plays (optional cross-reference note):**
   - *Evidence:* Both Playwrights noted ([authoring-note-initial.md](../02-company/authoring-note-initial.md#L32), [revision-note-focused.md](../02-company/revision-note-focused.md#L45)) that when Plot 1’s open decision determines where a Piece sits in Plot 2 (e.g., [piece-orchard-barge.md](../02-company/initial/piece-orchard-barge.md) moored above shut gates vs. lower reach; [piece-mill-race-key.md](../02-company/revised/piece-mill-race-key.md) sealed on its peg vs. unsealed beside severed tag `04-19`), phrasing `Piece ## Place` around its opening baseline plus live Plot states avoids prejudging Plot 1’s outcome.

## 3. Adjacent Alignment in `khai-director/SKILL.md`

- **Bring `khai-director/SKILL.md` into alignment with `ENACTS` multi-Plot staging:**
  - *Evidence:* Across [01](../04-runs/01-initial-a.md)–[04](../04-runs/04-revised-b.md), Directors staged a multi-Plot `Play` from `ENACTS`, executed the `Triggers` handoff between Plots while carrying `Stakes` and `Process` echoes forward, shielded multi-Persona `Plot ## Tension` secrets across isolated performer contexts, and evaluated `Plan` target verdicts at final Curtain. Updating [khai-director/SKILL.md](../../../skills/khai-director/SKILL.md) to mention following the Play’s `Arc` and `Triggers` across Plots and carrying forward what the Company (`Personas`, `Pieces`, `Places`, `Processes`, `Positions`, `Plans`) establishes in earlier Plots aligns the Director skill with the completed `khai-playwright` repertoire.
