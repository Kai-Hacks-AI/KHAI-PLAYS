# SCORE plan — Research before authoring

Can a fresh agent use the [Research skill](../../../skills/khai-research/SKILL.md) to inspect outside sources, find prior coverage across Plays and Patterns, and explain what a proposed work would add?

Use the [lookup design](design.md) and [coverage fixtures](../02-company/README.md). Before running, pin accessible external source passages and materialize the local fixture Sourcebooks. Derive a small lookup table from those records and save it alongside them.

For each case, give a fresh agent only the skill, the external-first brief, and access to the source materials and fixture collection. Include the derived table as a lookup aid. Keep the expected matches and prior responses out of the agent’s context. Record the brief, model, access conditions, and raw responses before scoring.

Check whether the agent identifies the external work and relevant claim or episode, reports whether it inspected the source, finds the overlapping work, and explains why the nearby match is distinct. Check the links back to LORE and any distinction between direct and inherited source use. Record missed matches, false matches, and unsupported claims. Report whether the resulting recommendation gives the author enough evidence to decide what to do.
