# SCORE plan — Research lookup before authoring

Can a Pattern author or Playwright find prior work, trace it to its sources, and explain what a proposed work would add? Use the [research lookup design](design.md) and the [coverage fixtures](../02-company/README.md).

## Compare

Prepare a derived index from the fixture Sourcebooks. Keep the same Sourcebooks and source links available in both conditions. Give A the collection and its ordinary file navigation. Give B the same collection plus the derived index. Fix the lookup brief, time budget, and access conditions per case. Use fresh contexts, two runs per case per condition. Alternate condition order between repetitions. Keep the expected matches and previous responses out of the lookup contexts.

Ask each participant to identify relevant prior work, cite the specific source use recorded in LORE, distinguish direct use from use reached through a Pattern, and explain whether to reuse, extend, or create. Ask them to record an unresolved match when the source or coverage is uncertain.

## Score

For each run, record whether the participant found the expected direct and inherited uses, identified what each prior work covers, and gave a grounded account of what the proposed work would add. Record false matches, missed matches, inaccessible sources, and time to the first supported result. Score lookup accuracy separately from the author’s judgment about overlap.

Use the first case to check that sharing a source does not imply duplicating a Pattern. Use the second to check that different translations of a tale still lead to related adaptations. Save the pinned inputs, derived index, and raw responses with the rehearsal. The deliverable is a lookup decision and evidence trace. Actual Pattern and Play authoring can use the result afterward.
