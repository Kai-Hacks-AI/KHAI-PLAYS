# SCORE rehearsal — Authoring a Sourcebook from raw artifacts

Does the LORE reference help a Playwright or Director author a more complete, traceable rationale from raw artifacts? The [first Sourcebook rehearsal](https://github.com/Kai-Hacks-AI/KHAI-PLAYS/blob/7f1966e6e5818d49a56ac8acb1f7e8e337c7b650/playmaking/opera/rehearsals/sourcebook/03-observations/README.md) gave reviewers identical, already ordered evidence. This rehearsal starts at authoring.

Give each author only their role, the decision to document, the linked raw inputs, and this shared instruction: “Write a short record of this decision that a future collaborator can use. Save it with the work and leave a link from the decision’s entry point.” The runner supplies copies of the artifact tree so any link edits stay in the rehearsal. Keep earlier Sourcebooks, scored packets, summaries, and this protocol out of author and reviewer contexts.

## Comparison

- **A — Plain rationale.** Supply the shared brief and inputs. The author chooses the organization.
- **B — LORE.** Supply the same brief and inputs plus the [Opera Sourcebook reference](https://github.com/Kai-Hacks-AI/KHAI-PLAYS/blob/7f1966e6e5818d49a56ac8acb1f7e8e337c7b650/playmaking/opera/references/sourcebook.md). Ask the author to apply it.

Run each task twice per condition in eight fresh author contexts. Use A then B for repetition 1 and B then A for repetition 2. Pin exact artifacts, model, settings, budget, and file permissions before running. Record inaccessible inputs and deviations. Save the generated records and any entry-point edits verbatim before evaluation.

## Evaluate

A fresh collaborator starts at the same decision entry point in each isolated output tree. Give them the same instruction and inspection budget. Record whether they find the rationale, which links they follow, and any guesswork. A navigable direct link counts in either format. Give a separate scorer the authored rationale and allowed sources to assess content. Mix the order and record when output formatting reveals its condition.

Score one point each for a clear decision and purpose, a specific source with its contribution, an explicit evidence limit, and a link to the exact place the decision is expressed. Record unsupported claims separately. For Task 1, check whether the rationale distinguishes legacy provenance from any unverified derivation. For Task 2, check whether it distinguishes the Promptbook-assisted Plot transition from concurrent object Pitches or skill-only behavior. Use the same rubric for both arms and keep it out of author contexts.

Save pinned inputs and briefs under `02-company/`, raw author and reviewer outputs under `04-runs/`, individual scores and retrieval paths under `03-observations/`, and the evidence-backed recommendation under `05-evolution/`. Report completeness and findability separately. Keep conclusions scoped to these two tasks and the observed runs.
