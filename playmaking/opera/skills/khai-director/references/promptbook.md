# Build a Promptbook

Describe how the experience works in performance. Say how people participate, what cues a response or handoff, and how information becomes available. The Play and Company files supply the particular people, places, objects, and events. Write the Promptbook in terms of roles, cues, and situations so it can serve several Plays that work the same way.

Each of the five chapters has a fixed job:

- [Human](human.md)
- [Agent](agent.md)
- [Collaboration](collaboration.md)
- [Knowledge](knowledge.md)
- [System](system.md)

Use those headings in order. Write only the conditions needed for the Human’s intended effect. Leave a HACKS chapter empty if it adds nothing.
Write each instruction so the Director and cast can act on it without looking up another production. In System, state how far the Director may vary the staging when the Human sets that condition.
