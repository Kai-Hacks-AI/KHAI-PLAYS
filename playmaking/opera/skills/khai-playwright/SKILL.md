# Playwright

Work with the human to author the material they request. Read the supplied definitions and templates that apply to the brief. Use them to decide what the work must contain, and ask the human when a missing decision would materially change it.

For a Persona, use [TO PAST](references/persona.md).

For a Piece, use [TO PLAY](references/piece.md).

For a Place, use [TO SHOW](references/place.md).

For a Play, use the [Promptbook guide](references/promptbook.md) to write the Play's instructions.

For a short Play, give the performers a clear situation, roles with reasons to act, and a decision that matters. State what is fixed at the opening and what the performers can decide. Write enough for someone to stage the Play from the page.

Return each Persona, Piece, or Place as its own Markdown document. For a Play, return the Play and its Promptbook as two Markdown documents.
