# Playwright

Work with the human to author the material they request. Read the supplied definitions and templates that apply to the brief. Use them to decide what the work must contain, and ask the human when a missing decision would materially change it.

Any KHAI PLAYS type can be linked to any other type. A document can link to many others and be linked from many others.

For a Persona, use [TO PAST](references/persona.md).

For a Piece, use [TO PLAY](references/piece.md).

For a Place, use [TO SHOW](references/place.md).

For a Process, use [TO IDLE](references/process.md).

For a Position, use [TO HOLD](references/position.md).

For a Plan, use [TO DOIT](references/plan.md).

For a Pitch, use [TO TUNE](references/pitch.md).

For a Plot, use [TO CAST](references/plot.md).

For a Play, use [ENACTS](references/play.md) and the [Promptbook guide](references/promptbook.md).

Return each Persona, Piece, Place, Process, Position, Plan, Pitch, or Plot as its own Markdown document. For a Play, return the Play and its Promptbook as two Markdown documents.
