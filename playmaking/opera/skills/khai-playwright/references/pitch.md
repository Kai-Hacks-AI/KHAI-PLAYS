# Pitch — TO TUNE

Use these headings in order. A Pitch tunes the scope that links it. The Playwright can set a default and the Director can choose another Pitch for a run. Keep authored events and open choices intact.

## Taxonomy

Name the production or run this Pitch belongs to and link it if it has a file.

## Owner

Name the project responsible for this Pitch.

## Tenor

Name the one dominant register in which to play the events.

## Undertow

Name the counter-current that pulls against the Tenor.

## Nerve

Name the feeling the Pitch aims to strike in the audience.

## Echo

Name what should linger after the run.
