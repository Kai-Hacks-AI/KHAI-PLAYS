# Pitch — TO TUNE

Use these headings in order. A Play-wide Pitch sets the default register for the whole Play. A Plot can call for a different Pitch for that scene. A Pitch tunes the scope that links it. A Persona, Position, or any other type can link several Pitches, and several documents can share a Pitch. When a scope links several Pitches, say which is the default and when the others apply. The Director can choose another Pitch for a run. Keep authored events and open choices intact.

## Taxonomy

Name the immediate group this Pitch belongs to and link it if it has a file.

## Owner

Name the project responsible for this Pitch.

## Tenor

Name the one dominant register in which to play the events. Use the [standard Tenors](pitch-defaults.md) as starting points or choose your own.

## Undertow

Name the counter-current that pulls against the Tenor.

## Nerve

Name the feeling the Pitch aims to strike in the audience.

## Echo

Name what should linger after the run.
