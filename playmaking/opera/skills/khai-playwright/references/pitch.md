# Pitch — TO TUNE

Use these headings in order. A Pitch tunes the scope that links it. Any KHAI PLAYS type can link a Pitch, including a Play, Plot, Persona, Position, Place, Piece, Process, or Plan. A Play-wide Pitch sets the default register for the whole Play. A Plot can call for a different Pitch for its scene. Pitches linked to individual objects shape how those objects are played or presented within the scene.

Several objects can share a Pitch or use different Pitches in the same scene. If one scope links several Pitches, say which is the default and when the others apply. The Director can choose another Pitch for a run. Keep authored facts, events, and performer choices intact.

## Taxonomy

Name the immediate group this Pitch belongs to and link it if it has a file.

## Owner

Name the project responsible for this Pitch.

## Tenor

Name the one dominant register in which to play the events. Use the [standard Tenors](pitch-defaults.md) as starting points or choose your own.

## Undertow

Name the counter-current that pulls against the Tenor.

## Nerve

Name the feeling the Pitch aims to strike in the audience.

## Echo

Name what should linger after the run.
