# Plan — TO DOIT

Use these headings in order. Write for a production or for people acting inside a Play. A Play can have shared and individual Plans. Several Plans can be active at once, and they can compete.

## Taxonomy

Name the kind of Plan from what it is for.

## Owner

Name what the Plan is for and link it if it has a file.

## Direction

State what the Plan aims to achieve and why now.

## Orders

Assign each move this Plan calls for to a Persona, Position, or role.

## Implementation

State the conditions and limits that shape how the work can be done.

## Targets

List this Plan’s observable results. Start each at `[ ]` (open), then record its verdict from what happens: `[x]` done, `[F]` attempted and missed, `[W]` dropped or overtaken, or `[-]` cut as moot or inapplicable. The Plan closes when every target has a verdict.
