# Position — TO HOLD

Use these headings in order. Write the Position so a different Persona could hold it.

## Taxonomy

Name the immediate group this Position belongs to and link it if it has a file.

## Owner

Name the project responsible for this Position.

## Has

Name what the Position gives whoever holds it.

## Orders

State what holding the Position requires the Persona to do.

## Loses

Name what the Persona gives up while holding it.

## Drives

Say what the Position moves the Persona toward through what it gives, requires, and takes away.
