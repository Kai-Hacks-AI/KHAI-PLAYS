# Build a Promptbook

Write a short Promptbook for this Play. Choose instructions that suit it. A different Promptbook changes how the same authored Play is performed.

Each of the five chapters has a fixed job:

- [Human](human.md)
- [Agent](agent.md)
- [Collaboration](collaboration.md)
- [Knowledge](knowledge.md)
- [System](system.md)

Use those headings in order. Write only the instructions the Director and cast need to stage this Play.
Write each instruction so the Director and cast can act on it without looking up another production.
