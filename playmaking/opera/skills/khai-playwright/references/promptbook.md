# Build a Promptbook

Write a short Promptbook for this Play. Choose instructions that suit it. A different Promptbook changes how the same authored Play is performed.

Each of the five chapters has a fixed job:

- [Human](human.md)
- [Agent](agent.md)
- [Collaboration](collaboration.md)
- [Knowledge](knowledge.md)
- [System](system.md)

Use those headings in order. Write only the instructions the Director and cast need to stage this Play. Use the [legacy Prose Standard](https://github.com/ChBrain/khai/blob/c8c56c7e843eac2eb33709d06ad1d7aca4dd8c00/packages/engines/spine/instructions.md) as an example you can adapt.

HACKS comes from the [KHAI Instructions canon](https://github.com/ChBrain/khai/blob/c8c56c7e843eac2eb33709d06ad1d7aca4dd8c00/packages/khai-arch/architecture/instructions.md).
